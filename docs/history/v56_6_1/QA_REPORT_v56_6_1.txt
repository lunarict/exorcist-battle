ODERZHIMYE 56.6.1 - VERIFICATION REPORT
2026-10-14

RESULT: 493 browser assertions and 121 static/integrity checks passed (614 total).
These are assertions, not 614 independent end-to-end scenarios or devices.
Machine-readable assertions: docs/verification.json.

METHOD
Headless Chromium via Playwright. Actual app markup, styles, scripts and material
assets were loaded through a local inline-resource harness (page.set_content).
External/live navigation is unavailable in this environment. Shipping files keep
their normal resource URLs; the harness does not modify release files.
Browser layout, native CSS/WAAPI animation and interaction tests are real, but this
method does not validate hosting, actual resource fetching, service workers or a
real persistent origin. Touch cases use emulated/synthetic input, not a phone.

LAYOUT / FUNCTIONAL - 392 assertions
320x568, 360x780, 390x844, 430x932, 768x1024, 1280x900, 1920x1080, 844x390.
Home horizontal fit; modal fit and scroll reachability; three category tabs;
entity descriptions; next/previous/picker; all seven rules chapters; full-text
search, search result jumps and empty search; modal scroll unlock; local four-
player generation; six traits; reveal/reseal; progress; game launches; restart
cancel. No uncaught JavaScript errors in the tested flows.

ENTITY CONTENT STRESS - 72 assertions
All 24 entities at 320px, 390px and 1280px. Full title width and detail scroll width
checked; both effect cards present. State is selected programmatically here;
normal user-operated entity navigation is covered separately above.

MOTION / INPUT - 29 assertions
Independent cover/leaf movement, return to rest, finite ribbon motion; oracle
shell/die/liquid timelines and repeat hover; keyboard focus/Enter/Escape;
reduced-motion; touch press/cancel/release/tap; retained effect unfolding and
trait reveal/reseal. Tests run in real-time, separately from the preview export.

STATIC / INTEGRITY - 121 checks
JavaScript syntax, unchanged core files and previous assets, unchanged visible
index text, index resource existence, all service-worker precache paths, new
material references, revision stamp, no bundled font files.

VISUAL REVIEW
Rendered mobile and desktop home/book/rules screenshots inspected. GIF preview
samples native browser animation timelines at 30 frames per second for a clean
visual demonstration. It is not a live device recording or FPS benchmark.

NOT VERIFIED
Physical iPhone/Safari or Android; production deployment and loading order;
service-worker update/offline behavior; real multiplayer; original ball GPU
performance; real-origin persistence; screen-reader use. These require a final
on-device/live-host check. This release does not claim device certification.

UNCHANGED
Original game data, text, generator, app.js and mobile-ball.js are byte-identical
to 56.6.0. Their preservation is an integrity check, not proof of every existing
feature. No network logic was added or rewritten in this visual iteration.
