ODERZHIMYE 56.6.0 - tactile presentation
Base: supplied v56.5.0 ORIGINAL COLORS UPDATED TRAITS FULL.

- Added a separate responsive presentation layer: tabletop.css and tabletop.js.
- Created small, locally bundled raster materials: felt, cotton stock, cloth,
  leather, pewter, and print flecks. No runtime procedural noise or image fetch.
- Preserved the restrained plum, cream, charcoal, and sage palette.
- Replaced the flat home controls with physical layered device cards, manual,
  clasp-bound grimoire and glossy globe. Existing labels and control IDs remain.
- Paper cutout masks retained; pigment and cast shadows occupy separate layers.
- Rebuilt header hierarchy, player tiles, status meter, book and rules layouts.
- Added finite staggered arrival and contact motion, hover reflections only for
  fine pointers, modal scroll lock, progress semantics and focus restoration.
- Added reduced-motion handling, safe-area offsets, larger hit targets and a
  16px mobile rules search input. No changes to game probabilities or text.
- Kept mobile-ball.js, original globe resources, styles.css and gameplay logic.
  app.js differs only in keyboard focus restoration in renderPlayerStrip().
- Revised HTML asset versions and service-worker cache name/precache entries.
- Moved older release documentation into docs/history; preserved the full
  original v56.5 trait text in the root.

Assets and dependencies
All added materials are original procedural rasters or vector shapes.
The outlined wordmark is an SVG graphic, not a runtime font dependency.
No new libraries, remote fonts, telemetry, accounts or backend are introduced.
Existing PeerJS networking and QR code integrations are unchanged.
