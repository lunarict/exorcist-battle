# v56.6.25 — баланс генератора и согласование характеристик

Отдельная сборка на проверку. Основа — EXORCIST_BATTLE_v56_6_24_ROLL_ALL_TRAITS_REVIEW.zip. На GitHub ничего не опубликовано. Исходный ZIP v56.6.24 сохранён.

## Изменения

Возраст и тип/пол обычного персонажа генерируются независимо. Возраст остаётся в Био вместе с именем и типом. Возрастные веса: 18–24 — 20%; 25–34 — 35%; 35–49 — 30%; 50–64 — 10%; 65–79 — 4%; 80–127 — 1%. Внутри диапазона каждый целый возраст равновероятен. Нижний порог 18 выбран для этой review-сборки. Это игровые настройки на согласование, а не реальные демографические частоты.

Типы: мужчина 45%, женщина 45%, трансформер 5%, рептилоид 5%. Для мужчины и женщины имя берётся из соответствующего словаря. Для необычных типов один раз выбирается мужской/женский пул имени (50/50), затем его метка используется для всех словоформ. Род не угадывается по последним буквам имени или фамилии.

В trait-catalog.js содержатся 750 исходных строк пяти остальных характеристик, с явно заданными мужскими и женскими вариантами. Общие формулировки одинаковы. У 7 избыточных точных копий и 3 близких пар общий идентификатор выпадения; 740 идентификаторов всего. Формулировки не удалены. М/Ж и синонимические варианты одной группы не увеличивают её шанс.

Выбор без возвращения ведётся отдельно для каждой категории. На границе циклов исключаются последние 40 выпадений; внутри партии повтор одной группы исключён. История сохраняется между последовательными партиями и перезагрузками в том же браузере. Если localStorage запрещён или заполнен, код продолжает работать с памятью страницы. Одновременные независимые вкладки и разные устройства не синхронизируют историю. В сетевом режиме генератор вызывается у хоста, как и раньше; клиент не перегенерирует полученные значения.

Особые персонажи остаются готовыми профилями с исходными возрастами; попытка выбора такого профиля 2% сохранена. Профили фильтруются по недавним совпадениям и участникам текущей партии. Все 14 шуточных имён, шанс 5%, словари имён/фамилий и доля предпочтительных имён 89% сохранены. Для шуточных имён и особых профилей также расходуется запас, чтобы не выбирать один вариант снова и снова.

87 правок правописания/грамматики/оформления и 181 запись с адаптацией рода/разделением альтернатив представлены в EXORCIST_v25_ALL_TEXT_CHANGES.txt и интерактивной HTML-таблице. Эти группы могут пересекаться. Полный каталог обеих форм включает и неизменённые строки. Все перечисленные правки применены только в review-сборке. Фраза «Не разводятся, но живут вместе» оставлена без смысловой замены; «Евнух» не получает выдуманный женский аналог и доступен только мужскому пулу.

## Сохранённые партии и приватность

Существующее сохранение не очищается и не перегенерируется. Продолжить партию означает продолжить ровно с сохранёнными значениями, в том числе со старым текстом. Для нового баланса нужно начать новую партию.

Схема player.character не расширяется идентификаторами текста, возрастом или полом. Она по-прежнему содержит только traits и scripted. Это важно: функция сетевой сериализации скрывает значения закрытых характеристик, и новые метаданные не должны раскрывать их обходным путём.

## Проверки

* 100 000 отдельных генераций возраста/типа, детерминированный тестовый seed: средний возраст 36,67186; доли возрастов и типов согласуются с заданными весами. Это тест алгоритма, не статистика пользователей.
* 10 000 обычных персонажей с чередованием мужских/женских форм: 50 000 выборов пяти характеристик; ноль повторов в последних 40 выпадениях каждой категории, ноль повторов категории внутри партии. История загружалась заново 100 раз.
* Полный первый цикл каждой категории без повторов; проверены окончания возраста 18, 21, 22, 24, 25, 111, 112, 121, 127.
* 8 000 персонажей через настоящие адаптеры app.js: согласование с именем и полом, начальные open/revealCount, уникальность имён в партии, достижимость всех 10 особых профилей. Все 14 шуточных имён достижимы в своих пулах.
* Невалидный JSON, неизвестные идентификаторы и запрещённое/переполненное хранилище не ломают генерацию.
* Chromium, 320, 390, 768, 1280 px: открытие/закрытие в reduced-motion, повторные нажатия, самые длинные мужские/женские формулировки, продолжение сохранения и проверка закрытых сетевых значений. Горизонтального переполнения текста не обнаружено. Для проверки API сохранения применён локальный RAM-адаптер, поскольку тестовая страница загружалась в память без сетевого origin.
* Отдельно при 390 px проверено обычное, не reduced-motion сворачивание Био: завершено, без fallback, 1120 мс, программный renderer, ошибок JavaScript нет. Это функциональная проверка, не замер мобильного FPS.
* Контрольные статические скриншоты v24/v25 при одних и тех же значениях и reduced-motion совпали пиксельно.

Ресурсы для Chromium подавались из архива локально, через тестовый обработчик запросов; опубликованный сайт не использовался. Настоящий iPhone/Safari, два сетевых клиента и установка/обновление PWA на физическом устройстве не тестировались. Проверено наличие всех 107 файлов/путей precache.
